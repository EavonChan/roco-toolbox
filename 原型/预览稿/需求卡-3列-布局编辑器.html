需求卡布局编辑器 · 3 列（真实 106px 宽）

宽度怎么来的：375 宽手机上，页面左右各 16px、需求中心区块左右各 10px，剩 323px； 3 列 + 2 个 2px 间距 → 每张卡最多 106px 宽（3×106 + 2×2 = 322，留 1px 余量）。
默认值 = 2026-11-01 定稿并已落地的设计（卡 106×95）：我缺的 / 需求中心 / 共同寻找 三页共用这套坐标。
拖动元素或用右侧输入框微调（滚轮缩放、双击改文字），改完点「复制布局 JSON」发我，我按 left / top / scale 1:1 落到代码，不做任何缩放换算。
名字与动作 / 状态固定整卡宽居中，只能上下调：这样「待承接」「已接」这类长短不同的状态文字都居中，不会首字同位。
文字压边：卡内画了 4px 安全区虚线，文字建议不要越过它；需要贴边的话把安全区关掉再调。
