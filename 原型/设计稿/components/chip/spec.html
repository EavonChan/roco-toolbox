chip

筛选 chip：可多选、可清空的筛选小块（蛋组 / 性格 / 体型 / 声音 / 账号）。

高 28 / 内联 26 variant: 纯文字 / 计数 / 图标 state: default / selected / disabled
与分段控件的区别：chip 可多选、可叠加、可全清；分段控件是互斥视角，只能选一个。 要「只能选一个」时用分段或单选。

A · 形态

纯文字（未选 / 已选 / 禁用）
带计数
图标 + 文案（体型 / 声音）
性格：
内联版（26 高、10px）

B · 状态

state视觉说明
default白底 + --line 描边 + --text-body可点
selected主色实底 + 白字 + 阴影aria-pressed="true"
pressed缩放 0.96移动端 :active 反馈
disabled浅灰字、无边框变化disabled

D · 布局约定

chip 容器用 flex-wrap: wrap + gap: var(--sp-8)； 一行放不下就换行，不许缩字号或截断。数量超过 12 个时折叠进「更多」。
