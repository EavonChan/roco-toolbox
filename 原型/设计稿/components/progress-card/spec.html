progress-card

进度卡：一块「分子 / 分母 + 进度条」的统计卡，回答「已经收了多少、还差多少」。

h2 标题 + 24px 数字 + 8px 条 variant: 静态 / 可点 state: default / hover / empty / loading
何时不用：只是「一个数字 + 单位」（如「11 个窝」）用 chip；需要看明细列表时用卡片网格， 不要在进度卡里塞列表。
