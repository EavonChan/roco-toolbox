segmented-control

互斥视角切换：一排按钮里只有一个「当前项」，用于切换同一块内容的观察角度 （种公推荐 / 母本缺口、追满分 / 追双牌、未收集 / 收集中 / 已收集）。

轨道高 34 / 分段 30 2~4 段 state: default / selected / disabled
何时不用：筛选项（可多选、可清空）用 chip；页面级导航用底部页签； 「点一下就执行」的动作用按钮。分段控件只表示互斥视角，不混维度。

A · 两段（最常用）

左侧选中
右侧选中
短文案

B · 三段（收集页状态）

三段没有固定宽度要求：插入到任何位置都行，标签必须完整显示——不缩字号、不加省略号。 容器比标签总宽还窄时，控件保持自身宽度（由父级让位），而不是把字挤掉。

三段 · 左侧选中
三段 · 末段禁用
塞进 140px 容器：字仍然完整（控件保持自身宽度，溢出容器也不缩字）
