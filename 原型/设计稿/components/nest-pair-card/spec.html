nest-pair-card

配对卡：一对配窝里的一只精灵（母本或种公），两张并排才是「一对」；一对由外层组卡的 左侧色条标出，色条颜色来自摆位图同一套 12 色，便于对号入座。

size: full 86 / home 70 variant: mother / stud / academy state: default / collected / hover 目标态：名字统一 10px + 精简形态
与 pet-card 的区别：pet-card 是「一只精灵一览」；配对卡是「一对里的角色」， 必须成对出现、带性别底色、带盒位/分贝/身高体重。所以是两个组件，不是同一个组件的 variant。

A · 一对配窝（组卡 + 左色条）

外层组卡承载「第几条线」的颜色；内部两张卡分别是母本（粉）与种公（蓝）。
