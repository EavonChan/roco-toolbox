### 2.1 底栏状态（拍板：最多两行）

| 条件 | 文案 | 配色 |
|---|---|---|

## 三、展开面板：就地展开、按性格分组（截图 ③）

### 3.1 为什么是就地展开（拍板）

- 不盖住蛋仓，不叠第二层弹层；筛选项一直看得见。
- 面板占满网格整行（`style={{ gridColumn: '1 / -1' }}`，**不能写死 `col-span-4`**——横屏网格是
  `repeat(auto-fill, 5.1rem)`，列数随宽度变，见 `src/index.css` L590-596）。
- 插在**被点的那张卡之后**，面板正好落在它下一行。
- 底部抽屉、独立列表页**不做**（拍板 2）。

### 3.2 面板规格

1. **标题**：`白发懒人 · 5 颗`；右侧「收起」。
2. **摘要**：`3 在背包 · 2 在家园 · 4 已标注 · 1 已挂出 · 1 换蛋中 · 1 待认领`；
   筛选命中 < 全量时开头补 `共 5 颗 · 当前筛选 4 颗`。每段不折行，只在 `·` 处换行。
3. **性格分组**：`平和 ×4`、`冷静 ×1`；颗数降序，相同颗数按首次出现；没有性格的归「性格未标注 ×N」。
4. **组内排序**：获得时间倒序（最近收的在上）；没有获得时间的家园蛋排该组末尾。
5. **每行**（约 44px，整行可点）：
   - 左：蛋图 30px；
   - 中上：体型 / 声音奖牌（都没有 → 灰字「体型/声音未标注」）+ 绿窝图标 + `自产 / 外部`；
   - 中下：`背包 / 家园 · 11-24 21:12`（没有时间 → 「无时间」）；
   - 右：状态芯片 + `›`。
6. **点行 = 现有「蛋详情」**（`ModalSurface size="xl"`，L243-332 原样复用）：蛋重、蛋高、获得时间、蛋组、
   实际父母、标注、挂出、标注所有同类蛋都在里面；聚合不复制第二套动作。
7. **待认领行**：整行淡琥珀底 + 琥珀芯片。
8. **筛选态**：只列命中的成员；标题摘要写全量 / 当前筛选。
9. **N 很大**：面板 `max-height: 60vh; overflow-y: auto`（第一版就加）。

### 3.3 行状态

| 状态 | 判定 | 芯片 |
|---|---|---|
| 待认领 | `claimPending`（F5 保底字段） | 琥珀 `bg-amber-50 text-amber-700` |
| 换蛋中 | `status === 'reserved'` | 蓝 `bg-sky-50 text-sky-700` |
| 已挂出 | `listed` | 绿 `bg-emerald-50 text-emerald-700` |
| 在家园 | `location === 'home'` 且未挂出 / 未认领 | 灰 `bg-slate-50 text-slate-500` |
| 未挂出 | 在背包、未挂出、未换蛋中 | 灰 `bg-slate-50 text-slate-500` |
| 已换出 | `status === 'transferred'` | **蛋仓入口就过滤（L140），看不到** —— 见 §10 |

## 四、筛选 / 搜索 / 排序

| 操作 | 现状 | 聚合后 |
|---|---|---|
| 搜索蛋名 | 按物种名过滤单颗 | 不变（物种级）；命中就整组显示 |
| 筛选 全部 / 已标注 / 未标注 / 自产 / 不可交换 | 过滤单颗 | **先过滤成员、再聚合**；`×N` = 命中数，命中 < 全量写 `×N/M` |

| 空态 | 「没有符合的蛋」/「这个角色还没有蛋」 | 不变 |

## 七、数据与实现（已落代码）

### 7.1 纯函数：`src/ui/plan/eggStockGroups.ts`

```ts
export type EggGroupMode = 'species' | 'species-nature' | 'strict';
export type EggGroupRowStatus = '待认领' | '换蛋中' | '已挂出' | '在家园' | '未挂出';

export interface EggGroupFacts {           // 面板把现有私有判定传进来，不搬函数
  natureText(e: WorkflowEgg): string;
  isGreenNest(e: WorkflowEgg): boolean;
  isSelfProduced(e: WorkflowEgg): boolean;
  isAnnotated(e: WorkflowEgg): boolean;
  isSpecial(e: WorkflowEgg): boolean;
}

export interface EggGroupItem { egg; selfProduced; greenNest; status }
export interface EggNatureSection { text; items }
export interface EggGroup {
  key; eggGameId; items; count;
  selfProduced; greenNest; listed; reserved; claimPending;
  bag; home; availableBag; annotated;
  natures; natureSections;
  latestObtainedAt?; latestConfirmedAt;
}

export function groupEggStock(eggs, facts, mode = 'species'): EggGroup[];
export function eggRowStatus(egg: WorkflowEgg): EggGroupRowStatus;  // 行状态，面板/组件共用
```

要点：

- **键**：`species:<eggGameId>`；特殊蛋 `special:<eggId>`（各自一组）。
- **组间排序**：任一自产 → 前；任一绿窝 → 再前；其余首次出现顺序。
- **`natureSections`**：颗数降序、组内时间倒序（无时间排后）；面板直接渲染，不再二次排序。
- **不改 model**：`StockEgg` / `reconcileEggStock` / `sortEggStock` 一行不动。
