## 附：给朋友的 PR 通道卡

直接发给他（或贴到 issue 里）：

```
分支：从 origin/test 开 friend/<功能>-<日期>，不要从自己的旧分支续；
     每天 rebase 一次 test，存活不超过 7 天，不要 rebase 已推送的历史.
粒度：一个 PR 一个目的，≤ 8 个文件 / ≤ 400 行，超了先拆.
验证：PR 描述里贴 npm run verify 的真实输出（tsc -b && vitest run && lint-copy）.
界面：可见变化附 375 / 390 截图或可交互 HTML.
边界：这些文件只有主线能改，要改先开 issue 说理由——
     src/ui/MotherView.tsx、src/ui/Dashboard.tsx、src/ui/plan/*、
     release/*、scripts/deploy*、.github/*、docs/设计资产/registry.json
合并：每周两次窗口，PR 绿了我这边才合；test 分支已开保护，不能直推.
```

助理（A）在每次 PR 进来时跑 6 项机械预检：落后提交数、冲突预演、重复补丁查重、`verify` 复跑、diff 规模与越界文件、UI 截图是否齐。
