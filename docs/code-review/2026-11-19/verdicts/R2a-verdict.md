## 2. R2a-H02 · 收蛋后状态从「已产出」退回「已上窝」
- **原结论**：蛋收走后下一轮会写更新的 `placed` 行，读取取最新，状态回退。
- **裁决：有条件成立，不是收蛋后必然回退。**
  - 回退需要同时满足：场景里仍有符合目标的配窝、任务仍有效、写入成功（`functions/_lib/eggPatrol.ts:97`）；满足时较新的 `placed` 会盖过旧 `produced`，读取没有产出优先级（`eggPatrolStore.ts:70`）。
  - 第三种情况：没有匹配配窝也没有匹配蛋时不写新观察，旧 `produced` 仍显示；若本轮命中歧义蛋，则可能变成 `ambiguous`（`src/shared/eggPatrol.ts:249`）。
- **对修复动作的影响**：报告的触发条件（「亲本还留在窝里」）需要写得更严格——必须「仍匹配目标」；验收用例要同时覆盖「配窝仍在 → 回退」「配窝已散 → 保持 produced」「多父本 → ambiguous」三种。
