## 中

### R2-4-M01 「全选」勾不满展开的全部性格，还会把已勾的非八大性格悄悄清掉

- **问题描述**：现状是自选性格点「更多」后格子里能勾全部 30 个性格，但下方「全选」永远只勾八大（8 个）；
  已经勾了八大以外的性格时按钮仍显示「全选」（因为数量对不上 8），点一下八大保留、其余勾选被静默清空。
  用户影响：想一键集齐所有性格做不到；误点一次「全选」，自己刚勾的性格就不见了。触发条件：自选性格 →
  更多 → 勾任意八大以外的性格 → 点「全选」。（证据：Coverage.tsx:236 按钮标签按
  `customNatures.length === targetNaturePool.length`（=8）判定；coverageFilterStore.ts:139-144
  `toggleAllCustomNatures` 全集只取 `targetNaturePool`；catalog.gen.json 实测 natures=30；
  依据：changelog 2026-10-30「自选性格改成两排 8 个，加『更多』可以选全部性格」——「更多」的可选集合
  与「全选」的作用集合不一致）
- **优化方案**：两个候选口径——A. 「全选 / 全部取消」作用于当前展示集合（收起时=八大、展开后=全部 30 个），
  标签按对应集合判定；B. 保持只操作八大，按钮文案写死「全选八大」并在存在池外勾选时不做清空。
  代价：A 需把「当前展示集合」传进 store 或把按钮逻辑抬回 Coverage 组件（约 15 行）；B 只改文案与边界。
  **产品口径二选一（改变用户可见行为），修复阶段保持现状，记「待用户确认」。**
- **优化后表现**：—（待拍板）。拍板后验收：补「勾池外性格后点全选不掉勾 / 文案与作用集合一致」用例，
  跑 `npx vitest run src/ui/myPetsFilterStore.test.ts src/ui/Collection.test.tsx`（视落点增补）。

### R2-4-L02 两个「清空筛选」入口同一件事各写一份

- **问题描述**：现状是 `clearMyPetsFilters` 与 `clearInventoryFilters` 函数体逐字相同（都只做
  `selected = new Set(); commit();`），一个给「重置本机导入数据」用、一个给精灵背包「重置」用。
  用户影响：无；以后若「重置」要多清一样东西，改一个忘另一个就分叉。触发条件：—
  （证据：myPetsFilterStore.ts:86-95 两函数体相同；依据：AGENTS.md 中风险条目「重复逻辑」，
  此处因语义尚一致降为低）
- **优化方案**：`clearInventoryFilters` 改为直接调用 `clearMyPetsFilters()`（两个导出名都保留，
  resetImportedData 与 MyPets 两个调用方不动）。代价：1 文件、3 行。
- **优化后表现**：一处实现、两个入口，日后改口径只动一处。验收：
  `npx vitest run src/ui/myPetsFilterStore.test.ts` 通过（其中「重置后写回 localStorage」用例锁定行为）。

### R2-4-L03 改了某个蛋组的推荐性格，「筛选非默认」圆点不亮

- **问题描述**：现状是种公阵列右上角的「筛选与默认值不同」提示圆点只看「蛋组有没有少选」和「是否自选模式」；
  推荐模式下在蛋组展开区增删性格（此时筛选已与默认不同）圆点不亮。用户影响：改过组内性格后收起的
  「筛选」按钮看上去像没动过，容易误以为当前是默认口径。触发条件：推荐模式 → 缺口明细展开任意蛋组 →
  取消或增加一个性格 → 看右上角「筛选」按钮。（证据：Coverage.tsx:150-152 只比较
  `groupIds.length` 与 `natureMode`；依据：StudMatrix.tsx:57-58 prop 注释「筛选与默认值不同：右上角小圆点
  提示」——该契约未覆盖组内性格这一维）
- **优化方案**：`filterActive` 补一段「`naturesByGroup` 与 `groupRecommendedNatures(targetNatures)` 默认值
  逐组比较」，用 useMemo 包住。代价：每次渲染 14 组 × ≤3 性格的比较，开销可忽略。
- **优化后表现**：组内性格有改动时圆点同样亮起，与注释契约一致。验收：`npx tsc -b` +
  相关单测（Coverage 无专属单测文件）；人工路径：推荐模式取消一个组内性格 → 圆点出现 → 恢复默认 → 熄灭。
