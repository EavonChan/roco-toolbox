**R2-7-L11 偏差说明（需要你知道）**：原始 `.pcap` 里的业务负载是**压缩帧**（zlib / gzip），字节级改字段会让帧失效；
上游解析器只提供「pcap → JSON」单向入口，没有反向封装能力，所以夹具保存的是**真实抓包解出的家园结构（脱敏 JSON）**，
而不是 `.pcap` 本身。它仍然打破了「夹具与实现同源」的问题（数值来自真实抓包：10 住户 / 11 小窝 / 5 对配对 /
