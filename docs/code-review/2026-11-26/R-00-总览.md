## 5. 最该先修的三条（三段式）

### R4-01 · P1 · 用户手动下架过的蛋，升级后被自动挂到组内广场

- **① 问题**：现在每次蛋仓同步结束，服务端都会把所有"字段齐全"的背包蛋重新评估一遍并置为已挂出（对组内可见、可申请换）；唯一豁免是"用户手动下架过"这个标记，而它只有**本次版本之后**的下架才会写。**用户影响**：升级前就下架过的私藏蛋（按仓库口径典型是满重蛋和要收藏的绿窝蛋）会在第一次同步后出现在组内广场，别人可以直接发起交换；用户什么都没点。**触发**：必然，所有在旧版下架过完整蛋的账号。（`eggWorkflow.ts:159-171`、`:163`、`:327`、`:336-337`）
- **② 修法**：在共享状态机加一个一次性时间标记（例如 `autoListSince`），只对"标记之后确认过的蛋"自动挂出，标记缺失时先写一次当前时间。代价：状态多一个字段，旧客户端会忽略（不破坏兼容）。选它而不是"客户端回填"的理由：判定在服务端，与设备无关。
- **③ 表现**：用户升级后不会发现私藏蛋凭空出现在广场；之后下架照旧生效。**验收**：`npx vitest run src/shared/eggWorkflow.test.ts`，新增"升级前 `listed=false` 的完整蛋，第一次同步后仍 `listed=false`"。

### UI-01 · P1 · 点「同步」到了一个没有同步按钮的页面

- **① 问题**：概览卡右上角的按钮登录后文案是「同步」，但点击只是切到「身份」二级页；而身份页用 `section !== 'identity'` 把「立即同步」「用本机覆盖云端」都隐藏了。**用户影响**：已登录用户点「同步」只看到用户名/改密码/退出，会以为同步已静默完成或功能坏了；真要同步得返回再滚到页面底部。**触发**：必然，所有已登录用户。（`ProfileHeader.tsx:69-76`、`Profile.tsx:201`、`AccountPanel.tsx:332/343`）
- **② 修法**：A（推荐，1 行）已登录时文案改成「账号」，诚实描述落点；B 保留「同步」但在数据页给同步卡加 ref，点按钮滚动直达到那一块（需同时处理 sticky 顶栏遮挡）。选 A：这是"文案与行为不一致"，A 零风险。
- **③ 表现**：首屏不再有"点了不起作用"的按钮。**验收**：`npx vitest run src/ui/ProfileHeader.test.tsx src/ui/Profile.test.tsx`，新增"已登录时文案为『账号』（A）或点击后 `account-sync` 存在（B）"。

### R4-10 · P1 · 「标注所有同类蛋」会改到看不见的角色，还会把绿窝刷错

- **① 问题**：点批量标注时，前端把**当前这颗**的性格/体型/声音/**绿窝**一起打包，服务端按 `accountId + eggGameId` 取出**所有**同物种蛋（不分游戏角色、不排除换蛋中、不排除异色特殊）逐颗无条件覆盖；任一颗不可流通就抛错、整批不写。**用户影响**：① 改到看不见的角色；② 一颗绿窝 + 一颗普通窝的同种蛋，点一次就把普通那颗标成绿窝；③ 同种蛋里有一颗在换蛋中，整批标注直接失败，用户以为是这颗蛋的问题。**触发**：②③ 必然（3 颗同种蛋有 1 颗换蛋中就是常见情形）。（`EggStockPanel.tsx:246`、`:173-180`；`eggWorkflow.ts:345`、`:349-356`、`:178-180`。注：`label-many` 本身是基线就有的，本轮把"同类 = 当前屏可见的同物种蛋"固化成另一套口径，接线后冲突会立刻显形）
- **② 修法**：A 给 `label-many` 加可选 `gameAccountKey`（只标当前角色）+ 跳过不可流通的蛋并回传"跳过 N 颗"；B `greenNest` 这类逐颗事实不随批量动作写、或只在空值时补。A+B 一起做，C（与聚合卡口径对齐）留到接线时。
- **③ 表现**：批量标注只影响当前角色、只影响能改的蛋，有跳过时有提示。**验收**：`npx vitest run src/shared/eggWorkflow.test.ts src/ui/plan/EggStockPanel.test.tsx`，新增"含 `reserved` 时成功且跳过"与"两个角色同物种只改选中角色"。

| 点"标注所有同类蛋"，别的角色、别的窝的蛋也一起变了 | 绿窝标记被标错；同种蛋有一颗在换蛋中时整批失败 | 只标当前角色、只标能改的蛋，改了几颗要说清 | 有换蛋中的同种蛋时批量标注仍成功 |
| 只看一个号时，另一个号的配窝页签是空的 | 窝数看起来变少，用户会按错的空位数配窝 | 那个号也按它的完整数据算一遍 | 切到出蛋号页签能看到它自己的种公配窝 |
| 「我的」页上写「同步」，点进去没有同步按钮 | 用户以为同步坏了 | 按钮改叫「账号」，或直接跳到同步那一块 | 点按钮能看到同步入口 |
| 横屏家园在"这份抓包里没有家园"时，刷新按钮不见了 | 最需要刷新的时候反而不能刷新 | 把刷新按钮也放进横屏布局 | 横屏 + 无家园记录时按钮仍在 |
| 在母本页打字搜索，列表先"整个铺开"再收回去 | 每次输入都闪一下、偶发卡顿 | 切换筛选时第一次就只画 2 组 | 输入后首屏只出现 2 组，再逐步补齐 |
