## 0. 一句话

你 2026-11-19 ~ 11-21 那批改动（`friend/20261119` = `fd877a1`）**已经整体合入主线 `test`**，
合并提交是 `302f92d`（2026-11-22）。代码不用重提，历史也在（`git log 302f92d^2`）。
接下来从新 `test` 开分支，只提「还没进的那几类」和以后的新东西。

## 1. 先确认基线（不要凭记忆）

```powershell
git remote add upstream https://github.com/sasaki-ishiran/roco-toolbox.git   # 已有就跳过
git fetch upstream test
git log -1 --oneline upstream/test
git merge-base --is-ancestor 302f92d upstream/test; if ($LASTEXITCODE -eq 0) { "merged" }
```

打出 `merged` = 基线对了。如果 `302f92d` 还不是祖先，说明你 fetch 的是旧主线，重跑 `git fetch upstream test`。

## 2. 自查「我这边还有哪些没进」（这一步不要省）

```powershell
git log --oneline upstream/test..HEAD
node scripts/review-pr.mjs <你的分支>
```

- 列表为空 → 没有待合入的提交，直接进第 3 步。
- 列表里出现这些 sha → **已经在主线里了，别再提第二遍**：
  `988bf63` `80664b5` `e41f7fe` `55f8fa7` `0050dca` `56f23cd` `4379a41`
  `ab51e32` `484bfaf` `8896bd4` `4190151` `8fe8c9f` `81f9d4f` `9d13047` `4b61b03`
  `c62cb50` `6018725` `be87393` `bb32138` `1c1d6c8` `c022ab3` `b5c66e4` `2023550`
  `5d905fa` `69ed5df` `6bbb5f5` `55ae963`
- 判断工具：`review-pr.mjs` 的「重复补丁」一栏；它按 patch-id 认，改了行号也认得出来。

## 3. 从新基线开分支，一个分支只做一件事

```powershell
git switch -c friend/<功能>-<YYYYMMDD> upstream/test
```

尺寸与验收：≤ 8 个文件 / ≤ 400 行、PR base 选 `test`、界面改动附 375 / 390 截图
（细节见 `.github/CONTRIBUTING.md`）。超了先拆，别攒大 PR。

完成标准：`git diff --stat upstream/test` 的文件数与行数都在阈值内，
`git log --oneline upstream/test..HEAD` 只有你自己新写的提交。

## 4. 提交前必须贴的真实输出

```powershell
npm run verify     # tsc -b && vitest run && lint-copy
```

PR 里贴命令和输出，不写「测试通过」。只跑相关测试时，写清跑了哪几个文件、为什么不全量。

## 参考 B：用户重新拍过口径的 4 处（改之前先读这一节）

这几处不是「漏合」，是产品口径改了，代码已按新口径落地。你从新 `test` 开分支会自动继承。

1. **收集默认性格：八大 → 推荐**
   `src/domain/coverageTargets.ts` 的 `buildDefaultFilter` 现在返回 `natureMode: 'recommended'`（每组推荐前 3）；
   八大 / 自选仍是可选模式。
   同时修了一个 bug：`src/ui/coverageFilterStore.ts` 的 `migrate` 以前会把用户选的「推荐」改回「八大」，
   现在合法值原样保留，只有缺失 / 脏值才回落默认。
2. **看板与种公页去掉「数据来源」说明块**
   `Coverage.tsx`、`Dashboard.tsx` 不再渲染 `<SourceNotice />`；CC BY-SA 署名留在导入数据页（`ImportPanel.tsx`）。
3. **e2e 期望跟着口径改**
   覆盖度每组性格数 8 → 3；看板不再断言 `CC BY-SA 4.0` 可见；背包默认断言「推荐性格」。
   照旧写 8 会红。
4. **测试环境补了一个包**
   `node_modules` 缺 `@alloc/quick-lru`（tailwind 依赖）。你本地 `npm run verify` 若报 PostCSS / quick-lru，`npm install` 一次即可。
