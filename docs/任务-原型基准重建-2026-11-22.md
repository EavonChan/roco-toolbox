# 任务书：原型基准重建 · 组件库 · UI 质量门禁（2026-11-22）

> 一次性工程，建议**单独开一个会话**（代号 P2）。理由：它要连续看几十个页面、产出大量文件，
> 和日常功能开发混在一个上下文里会互相污染。
>
> 前提：不改 `src/`、不改线上、不打包不发版。所有产出落 `原型/` 与 `docs/设计系统/`。

## 一、目标（一句话）

以**线上已发布版本**为唯一标准，把每个页面重建成可交互原型，作为**最原始设计稿**；
以后所有方案都在这套设计稿上增量维护；并从中提炼组件库与 UI 质量门禁。

## 二、为什么要做

现在原型散在三处（`原型/编辑器`、`原型/预览稿`、`docs/prototypes`），而且都是"某次改动"的快照，
不是"当前线上长什么样"的基准。结果是：

- 做新方案时没有可信的起点，只能重新截图、重新猜；
- 同一个卡片在不同稿子里尺寸不一致；
- 提 PR / 审 UI 时没有可对照的基准，"看起来对"就算过。

## 五、执行顺序

### 阶段 0 · 基准固化（先做，别急着画）

1. 用 Playwright 跑线上站 `https://roco-toolbox.pages.dev`，逐页截 **375 与 390 全页图**，落到 `_基准截图/`。
2. 从现有代码提取设计 token：`tailwind.config.js`、`src/index.css`、`src/ui/primitives/*`。
3. 写 `tokens.css` + `shell.css`（真实屏宽容器、状态切换、参考线、元素边框）。
4. 产出 `原型/设计稿/README.md`：页面清单 + 每页基准截图链接。

**验收**：截图齐全、token 与代码一致（抽查 5 个颜色/字号）、外壳能同时展示 375 与 390。

### 阶段 1 · 六个主页面重建成静态稿

每页顺序：基准截图 → 结构骨架（无样式）→ 样式还原 → 状态补齐（空/加载/异常）。

- 只还原**线上真实存在**的东西，不要顺手加未上线功能。
- 每页完成后**先给用户看**：375 / 390 截图 + 与基准截图的差异清单，确认后才做下一页。

**验收**：六页可交互稿与线上基准并排看不出结构差异；差异清单里没有"忘了做"的项。

### 阶段 2 · 二级页与浮层

同上，按 §四 清单逐项推进。浮层要能真实打开/关闭，不能只画静止状态。

### 阶段 3 · 组件库提炼

从重建好的页面里倒推组件，而不是凭印象列。每个组件写：

| 字段 | 内容 |
|---|---|
| 名称 | 例如「精灵卡（160px）」 |
| 截图 | 375 与 390 各一张 |
| 状态 | 默认 / 悬停 / 选中 / 禁用 / 空 |
| 尺寸与间距 | 宽高、内边距、字号、行高、圆角 |
| 用在哪 | 哪些页面用、出现条件 |
| 与旧稿差异 | 与 `docs/prototypes` 里的旧实现不同之处 |

组件至少覆盖：精灵卡、需求卡、推荐卡、筛选 chip、分段控件、底部弹层、悬浮窗、空状态、按钮、开关、进度条、角标。

### 阶段 4 · UI 质量门禁

写成可执行条文，每条都要有"怎么检查"，不能只写"要求一致"：

1. **颜色**：只能取自 `tokens.css`，新增颜色必须先进 token 并说明用途。
2. **字号与行高**：只允许 `tokens` 里定义的档位；卡片内最小字号不得低于线上基准。
3. **间距**：以 4px 为栅格；非 4 倍数要在评审里说明。
4. **断点**：375 / 390 / 平板 / 横屏四档必须都看，截图缺一档不算交付。
5. **文案**：沿用 `tools/lint-copy.mjs` 规则（教学只留教程体系）。
6. **组件复用**：相同形态必须用组件库里的组件，新形态要先补进组件库再使用。
7. **对照检查**：改动页面与基准截图的差异必须能逐条解释，解释不了的算回归。

可选（若时间允许）：写一个 Playwright 截图对比脚本，对指定页面在 375/390 下与基准图做像素差，
超过阈值就 fail——这才是能进 CI 的门禁。**没有脚本时，门禁靠清单 + 人审，也要写清楚。**

## 六、硬规则

1. **只读线上**：可以截图、可以量尺寸，不要改线上任何东西。
2. **不改 `src/`**：这是原型工程，不是实现工程。发现线上与代码不一致，记录下来，不顺手改。
3. **每页先确认**：没有用户确认就往下画，等于白干。
4. **目录遵守** `docs/文件存放规范.md`：新原型只进 `原型/设计稿/`。
5. **不删旧稿**：`原型/预览稿`、`原型/历史`、`docs/prototypes` 都保留，组件库文档里标注"替代了哪个旧稿"。
