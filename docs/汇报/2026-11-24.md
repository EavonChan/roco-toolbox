# 2026-11-24 工作汇报（示例）

> 这是一份放在 `docs/汇报/` 里的示例汇报，用来验收工作台的「汇报」视图：
> 它能列出这个目录下的 Markdown，在右侧按标题层级、表格、列表、代码块、链接渲染出来。
> 汇报本身**只读**：工作台不会改这里任何一个字节。

最后更新：2026-11-24 09:40

## 一、本轮做了什么

1. 服务端加了两个只读接口：`GET /api/reports` 列文件，`GET /api/reports/<文件名>` 回原文；
2. 前端在顶部视图切换里加了第三个 tab「汇报」，左边文件列表按修改时间倒序，右边渲染正文；
3. Markdown 渲染是自己写的（不到 120 行），**没有引入任何 npm 包**，整套工具仍然零依赖、可离线跑；
4. 路径穿越一律 400：`..`、绝对路径、非 `.md`、带路径分隔符的名字都进不来。

## 二、验收结果

| 验收项 | 结论 | 凭据 |
| --- | --- | --- |
| 列表能列出这份文件 | 通过 | `GET /api/reports` → `count: 1` |
| 表格有边框 | 通过 | `th` / `td` 计算样式 `border: 1px` |
| 标题层级 | 通过 | `h1` 20px、`h2` 16px、`h3` 14px |
| 路径穿越 | 通过 | `GET /api/reports/../package.json` → `400` |
| 三个旧验收脚本 | 通过 | `check` / `check-ui` / `check-approve` |

## 三、几个取舍

- **不引第三方解析器**：一边是"包要能离线跑"的硬要求，一边只需要一小撮语法，自己写反而更可控；
- **解析失败不白屏**：空文件给空态文案，渲染抛错就原样吐 `<pre>`，正文下面还留一个「看原文」折叠块；
- **只读一个目录**：服务端用原始请求路径判穿越（`new URL()` 会把 `..` 折叠掉，不能靠它），再用 `realpath` 核一遍真实位置。

### 接口形状

```jsonc
  ]
}
```
