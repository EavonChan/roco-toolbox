## 七、发版中遇到的两个坑

1. **release 工作区缺本地构建私货**：`local.properties`（sdk.dir）、`keystore/roco-release.jks` 都在 `.gitignore` 里，worktree 没有 → 先报 `SDK location not found`，后报 `SigningConfig "release" is missing required property "storeFile"`。解法：从主工作区把这两样复制进 release 工作区（都是被忽略文件，不污染 `git status`）。
2. **`gradle.properties` 是受跟踪文件**：不要整个覆盖，会被 git 看到（本次已 `git checkout` 还原）。
