## 五、规则

1. **派活当天**就在「进行中」加一行，写清派给谁、什么时间。
2. **收到回信**立刻更新「最近进展」，然后做收口核对（不信自述，查提交/测试/文件）。
3. **收口后**从「进行中」移到「已完成」，并写凭据（commit / 文档 / 部署 ID）。
4. 需要用户决策的，进「等你」，不留在对话里。
5. 这一页和 `docs/会话台账.md` 的分工：台账管"哪个会话能干什么"，看板管"眼下每件事到哪一步了"。
