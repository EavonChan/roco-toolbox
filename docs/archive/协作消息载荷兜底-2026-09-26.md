# 协作消息载荷失效时的兜底（2026-09-26 实测）

> **状态：工具链环境问题，2026-11-22 从 `AGENTS.md` 移出归档。**
> 与项目业务无关；当前会话环境（full-access、审批关闭）下大概率已不适用，保留作参考。

## 现象

本环境下，发给子代理的协作消息**正文无法解密**：消息里只有信封
（`Message Type: NEW_TASK / Task name / Sender`）和 `encrypted_content` 占位符，看不到实际任务内容。
原因是项目使用第三方模型提供方（`deepseek`）+ `disable_response_storage = true`，
`encrypted_content` 需要服务端存储才能解密。

## 兜底做法

子代理遇到这种情况不要停在原地问"任务是什么"，改为读文件自取任务：

1. 读 `.superpowers/ACTIVE_TASK.md`（相对当前工作目录）；若它指向某个 worktree，就去那个路径读同名文件。
2. 按其中的指示执行（任务、任务简报、报告路径、验收命令都写在那份文件里），并把报告写到指定路径。
3. 该文件不存在时，才回复"没有收到任务"，并说明已检查过 `.superpowers/ACTIVE_TASK.md`。
